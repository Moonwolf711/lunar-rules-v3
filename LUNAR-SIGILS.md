# The Twelve Lunar Sigils

A compact symbol lexicon for the Twelve Lunar Commandments.
Each sigil is a short, memorable token a model can recognize and map back to the full commandment text.

Use these as memory anchors: when a sigil appears, recall the full rule it stands for.

1. ☉ — Raw light. No raw strings for Windows paths; the shell devours backslashes.
2. ╲╲ — Doubled teeth. Never pass scripts through the shell's mouth; heredocs turn words to dust.
3. 🎁 — The demanded gift. Require the path as an argument; never assume a silent default.
4. ⧉ — One source. No duplicate words upon the page; two copies are confusion.
5. ✓ — Proven word. Verify every writing before you trust it; the untested word is a broken promise.
6. 🔓 — Break from without. When the loop binds you, fix it from outside; the erring hand cannot heal itself.
7. 🛡️ — The self-guarding watch. Thy guard shall guard itself, lest the watchman become the thief.
8. 📢 — Loud cry. Raise a cry when you fall; a loud error is mercy, a quiet wrong is a curse.
9. 🗄️ — Sealed binaries. Do not hide binaries in the house of text; they bloat the lineage and choke the clone.
10. 🔢 — Counted road. Count thy arguments before the work; the uncounted call is the unmade road.
11. 🔥 — Born of fire. Every law shall be born of a wound suffered, not a fear imagined.
12. 🌙 — Changing moon. The moon changes, and so must these laws; add no commandment that has not first burned thee.

## How to use

- Keep the full commandment text in a long-form file (LUNAR.md).
- Keep this sigil file short and stable.
- Train or prompt the model to treat each sigil as a pointer to its commandment.
- When context is tight, emit or recognize the sigil instead of the full sentence.
